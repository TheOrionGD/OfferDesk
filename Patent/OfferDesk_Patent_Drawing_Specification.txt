FIG. 2: NLP VECTOR MATCHER & DYNAMIC PARAMETER WEIGHTING SUB-SYSTEM (112, 114)
--------------------------------------------------------------------------------
Sub-system Title: NLP VECTOR MATCHER & DYNAMIC PARAMETER WEIGHTING (112, 114)

Component Elements:
- Group Box (112): NLP VECTOR MATCHER MODULE
  - Box: Job Text T_job / Candidate Text T_cand
  - Box: Embedding Function E(T) (SentenceTransformer 'all-MiniLM-L6-v2', d=384)
  - Box: Cosine Similarity Computation: Score_similarity = (E(T_job) . E(T_cand)) / (||E(T_job)|| * ||E(T_cand)||)
  - Box: Output Score_similarity
  - Exception Box (Dashed): Model Unavailable / Offline Exception
  - Box: Sparse TF-IDF Fallback Vectorizer over unified vocabulary V
  - Box: Output Score_TFIDF
- Group Box (114): PARAMETER WEIGHT REDISTRIBUTION ENGINE
  - Box: Detect Omitted Candidate Attribute (e.g., missing GPA attribute g = null)
  - Box: Exclude Missing Weight (w_gpa) from Active Weight Set
  - Box: Compute Normalization Constant Omega_norm = sum of active weights
  - Box: Compute Renormalized Weights w'_i = w_i / Omega_norm
  - Box (Bold): Output Composite Match Score (0.0 – 100.0)
- Note Box (Dashed): Similarity sub-score from Module (112) is supplied as active input S_i to Weight Redistribution Engine (114).

Interconnections:
- Flow arrows connecting SBERT Embedding -> Cosine Similarity -> Score_similarity.
- Conditional arrow on exception triggering Sparse TF-IDF Fallback -> Score_TFIDF.
- Flow arrows in Module (114) connecting Omitted Metric Detection -> Exclude Weight -> Compute Omega_norm -> Renormalize w'_i -> Composite Match Score.
